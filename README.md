First GitHub project!

This is an Android list app that allows you to create multiple customizable lists. It was created using Google AI Studio, and I am learning more about the actual code in order to try and improve minor issues in the app, such as odd button formatting.

I created this app because while there are many existing list/note apps for Android, none of them did everything that I wanted it to. So I gave myself a crash course in vibe coding and Android Studio to make my own. This app will always be free to use, and I don't ever plan on putting in ads or any in-app purchases. I also don't know how long I'll be actively maintaining this, which is part of the reason I'm just going ahead and making everything public, so if you want to take it and make it your own, have at it! I do welcome comments, feedback, suggestions, etc, because I'm very green and just starting out learning how to code for Android. I made this because I needed to fill a specific need, not because I wanted to learn how to program mobile apps (though the process so far has been fun, so I will probably see what else I can make!)

Item Categories:
Default categories are "Task", "Idea", and "Note".
"Task" items have a checkbox that can be checked both in-app and in widgets. All other category types have their own icons.
Create your own custom categories for the ultimate list management system. "Shopping" for items to buy, or maybe "Gift Idea" for... you guessed it... gift ideas. Whatever categories you want, you can create and select an icon to go with it. These can also be managed on the Settings page.

Rich text editor and image upload option lets you add as much detail as you need to each item. (The "attach sticky notes" option just adds an image. I need to get rid of it; you can just ignore it for now.)

Creation date is automatically added, and you can add an optional due date, which will display in widgets.

Priority tags help you see what's most important, and General tags allow you to sort through your items as granularly as you want.

Add sub-tasks to any item category type. Subtasks are visible both in-app and in widgets.

### Priority Tags

<img width="270" height=" 287.75" alt="app_settingspage_prioritytags" src="https://github.com/user-attachments/assets/0e6b9391-a83a-482e-ad69-f5b915d958c9" />
