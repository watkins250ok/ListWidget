I love lists. I am a lists gal. I'm also very particular about the way that I want to use my phone. I could not find a list-making app that did everything I wanted it to, so I used Google AI Studio to build my own (as a bonus, I'll be able to tinker with this code and learn more about actual Android coding instead of just vibe coding!)

# About:<br>

ListWidget lets you create multiple customizable lists. Make a to-do list with items to check off. Create a list of movies/shows you want to watch, or books you want to read. My main list is a braindump, where I store thoughts and ideas as they come to me until I can action them, because if I don't write things down, they will cease to exist in my brain.

# Features:<br>

- Create as many lists as you want (I didn't code in a limit; I haven't tested this with a large number of lists yet to see what happens)
- Re-order your lists how you want.
- Add sections within lists to organize items.
- Filter and sort views.
- Add rich-text notes and images to items.
- Add tags for even more organization.
- Homescreen widgets let you see all of your lists, all of your items, or a specific list at a glance; view and check off items without opening the app.
- Change the color and font used in the app.
- Change the color and font size of widgets.
- Use dark mode, light mode, or system setting
- Private: anything you add to this app is stored completely on your device, and never uploaded to a server.
- 100% free: I don't intend to ever charge for this app, or include any paid features. I also do not intend to ever add advertisements. I built the app that I wanted to use, and am making it available for anyone else who would like to use it.
- Open source: Tweak it, re-code it, add stuff, remove stuff, have at it.
